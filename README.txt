JAEHYUN GLOBAL — ALBUM-INSPIRED WEBSITE

This package contains:
- index.html: responsive website designed to closely follow the approved album-collage mockup
- assets/jaehyun-album-collage.jpeg: the collage image supplied by the site owner
- .pages.yml and data/*.json: Pages CMS configuration and editable content

CLOUDFLARE PAGES DEPLOYMENT
1. Extract this ZIP. Keep index.html, .pages.yml, data/, and assets/ together at the project root.
2. Upload the extracted folder to Cloudflare Pages using Direct Upload, or connect a GitHub repository.
3. To use Pages CMS, publish the project from a GitHub repository and connect that repository at https://app.pagescms.org/.
4. Pages CMS edits the JSON content in data/. A Git commit triggers a new Cloudflare Pages deployment.

NOTE
The site uses the collage image supplied by the owner as its visual artwork. Replace it with individually licensed/authorized images if you want separate portraits or album-specific image panels. Update the placeholder links and text in Pages CMS before public launch.
